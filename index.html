How I work

A dashboard is only useful if someone acts on it

The same four steps run through every project, whether it is a Power BI report or a requirements document.

Ask

Start with the business question, not the chart. What decision does this dashboard need to support?

Clean

Check, fix and reshape the data in Power Query or Excel, so every number on the page can be trusted.

Model

Build the measures and KPIs that answer the question, such as return rate, order value and trends over time.

Explain

Turn findings into plain-language insights and clear recommendations a manager can act on.
